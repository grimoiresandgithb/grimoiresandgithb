📚 Alyssa’s Book Grimoire
A book‑review portfolio blending code, design, and literary magic

Welcome to my personal book‑review website, built with HTML, CSS, and a curated witchy color palette. This project brings together my love for reading, gentle design, and front‑end development. It lives on GitHub Pages as a long‑term portfolio piece and a cozy digital home for my reviews.

✨ Features
A clean, parchment‑inspired layout using a custom witchy color palette

Individual review pages with sections for summary, thoughts, and quotes

Organized folder structure for scalability

Fully static site hosted on GitHub Pages

Designed to feel warm, bookish, and a little magical

🎨 Color Palette

🚀 Running the Site
This project is hosted using GitHub Pages.

To view it locally:

Clone the repository

Open index.html in your browser

To deploy:

Push changes to the main branch

GitHub Pages automatically updates your live site
